# Figma → токены

## Главное правило
**Читать весь набор переменных, а не только использованные в кадре.** `get_variable_defs` по узлу отдаёт лишь привязанные к узлу переменные и только значения текущего режима: так можно пропустить тёмную тему, hover-цвета и целые коллекции. Полный набор читается через `use_figma` (только чтение, один вызов; перед вызовом прочитать `figma-use`).

## Шаги
1. **Чтение (`use_figma`, read-only):** `figma.variables.getLocalVariableCollectionsAsync()`, `getLocalVariablesAsync()` (значения по каждому режиму; алиасы разворачивать через `getVariableByIdAsync`; алиас с прозрачностью приходит как `{color: alias, opacity}`), `getLocalTextStylesAsync()` (размер, шрифт, интерлиньяж, трекинг, `textCase`).
2. **Сверка с кадрами:** `get_variable_defs` по нужным узлам — для проверки, что используемые переменные есть в полном списке. Переменные, которых нет в файле (приходят из внешней библиотеки), не переносить без решения пользователя; записать в `docs/tokens-map.md` как «не перенесено».
3. **Запись в CSS.** Три слоя в `tokens.css`:
   - примитивы → `:root { --primitive-… }` **без** Tailwind-утилит (в компонентах не используются);
   - семантика, режим по умолчанию (Light) → `@theme static { --color-… }`, значения ссылками на примитивы: `var(--primitive-neutral-900)`; алиас с прозрачностью → `color-mix(in srgb, var(--primitive-…) 6%, transparent)`;
   - остальные режимы → `:root[data-theme="dark"] { … }`, только токены, чьё значение отличается от основного режима.
   `--color-*: initial` отключает палитру Tailwind: существуют только токены дизайна.
4. **Имена:** `theme/{группа}/{имя}` → `--color-{группа}-{имя}`; `borders & dividers` → `border`; пробелы → дефисы, нижний регистр; очевидные опечатки исправлять в CSS (не в Figma) и вносить в таблицу «проблемы в именах». Не придумывать смысловых переименований сверх нормализации. Шрифт-имя по роли, а не по названию в Figma (`font-family-serif` у Manrope → `--font-display`).
5. **Типографика:** примитивы `--type-size-*`, `--type-line-height-*`, `--type-letter-spacing-*`, `--type-weight-*` (px → rem при 16 px); каждый текстовый стиль → `@utility type-{группа}-{размер}` в `typography.css`; `textCase: UPPER` → `text-transform: uppercase`. Значения брать из стиля, а не из ближайшей переменной (они могут расходиться).
6. **Выведенные токены** (если в Figma нет переменных): расстояния — проверить кратность сетке (шаг 4 px → шкала Tailwind), радиусы, колонка контента, брейкпоинты, боковые отступы; записать в `docs/tokens-map.md` раздел «Выведенные» с источником значения.

## Проверка
- Число семантических цветов в CSS = число цветовых переменных в Figma минус служебные (например, строка `current_theme`); число стилей = числу текстовых стилей.
- Тест на тему (Playwright): переключение `data-theme="dark"` меняет фон страницы и шапки на значения Dark (`tests/header.spec.ts`). Перед снимком ждать окончания `transition` и убирать курсор с кнопки.
- Обновить `docs/tokens-map.md`: что перенесено, что нет и почему, какие имена исправлены.
