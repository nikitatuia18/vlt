# Визуальная сверка

1. **Сервер.** `npm run dev` (http://localhost:5173); если уже запущен — переиспользуй.
2. **Эталон.** `get_screenshot` по nodeId из `docs/figma-map.json`; запомни размер кадра Figma и ставь такой же viewport.
3. **Снимок.** Playwright (`tests/`): открыть страницу, дождаться шрифтов (`document.fonts.ready`), снять элемент блока (`[data-el]` / секция). Для анимации — остановить время или снимать в t=0, середине и конце; для `@0N` кадров сопоставлять с соответствующим кадром Figma.
4. **Сравнение.** Визуально по двум изображениям + числа: позиции, размеры, цвета, межстрочные, отступы. Допуски: позиция/размер ±1px, цвет — точное совпадение с токеном.
5. **Отчёт.** Список «критично / заметно / мелочь»: слой, что в Figma, что в коде. Артефакты — в `tests/artifacts/`.
6. Код не правим — только отчёт; правки делает вызывающий.
