# Блок Figma → React

1. nodeId блока — из `docs/figma-map.json`. Нет записи → сначала добавь (имя слоя, nodeId).
2. `get_design_context` + `get_screenshot` (эталон). Вывод — референс; переписываем под проект.
3. Структура: `src/components/blocks/<Block>/<Block>.tsx` (+ `index.ts`). Имя компонента = PascalCase от имени слоя блока (`how-it-works` → `HowItWorks`). Классы/ключи элементов — из имён слоёв (`hero__title` → `data-el="hero__title"` или класс).
4. Стили: только Tailwind-утилиты на токенах и классы типографики из `typography.css`. Любое значение без токена — вынеси вопросом, не хардкодь.
5. **UI Kit первым делом.** Перед разметкой открой `docs/ui-kit.md` и `/ui-kit`: кнопки, иконки, контейнер, тема — только готовые компоненты. Чего нет, но встретилось второй раз, — вынести в `src/components/ui/`, добавить в витрину и в `docs/ui-kit.md`. Значение без токена — не выдумывать: ближайший токен или оформленное исключение (см. `CLAUDE.md`).
6. Ассеты: `download_assets` → `src/assets/<block>/`, имена по слоям (`img-…`, `icon-…`).
7. Семантика и a11y: правильные теги (`section`, `h1–h3`, `button`, `a`), `alt`, фокус.
8. Анимации не делаем (этап 5), но оставляй стабильные якоря: `data-el` у слоёв, которые будут анимироваться.
9. Подключи в `src/App.tsx` в порядке макета; `npm run build` должен проходить.
10. Запиши `docs/blocks/<block>.md`: что в блоке, ассеты, компоненты `ui/`, открытые вопросы.
