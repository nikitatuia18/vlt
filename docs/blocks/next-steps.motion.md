# Блок next-steps: спек иллюстраций шагов

Статус: **принято дизайнером на тестовой странице и подключено к карточкам (2026-10-21); тестовая страница `/steps-test` удалена.** Правка дизайнера: точки на вершинах и линии тоньше, аккуратнее — общие значения в `src/lib/hypercube.ts` (`edgeWidth` 0,45–1,3 px, `cornerRadius` 1,8–5,6 px, прозрачность по глубине), одинаковые у картинок шагов и тессеракта Crypto Processing. Идея, согласованная с дизайнером 2026-10-21: **лестница измерений** — шаг N вырастает до N-го измерения: 01 отрезок, 02 квадрат, 03 куб, 04 тессеракт (тот же объект, что в карточке Crypto Processing блока Features). Стиль тессеракта: тонкие линии и точки, 3D, цвет линий — цвет текста темы (в Dark светлый), цвет бренда только акцент; ближе к глазу толще и темнее. Код: `src/components/blocks/NextSteps/illustrations/` (`scenes.ts`, `StepIllustration.tsx`), общая математика гиперкуба — `src/lib/hypercube.ts` (её же использует тессеракт Features).

## Привязка ко времени
Кадр картинки = прогресс `p` оранжевой линии шага (0 → 1 за `STEP_SECONDS` = 5 с); у картинки нет своих часов, всё (и вращение) — функция от `p`. Поэтому: удержание карточки нажатой останавливает картинку вместе с линией; клик по другому шагу перезапускает с нуля; пока карточка закрыта, ничего не рисуется; при `prefers-reduced-motion` рисуется кадр `p = 0,78` (как линия в макете).

## Сюжеты (по `p`)
| Шаг | Фигура | `p` | Что происходит |
|---|---|---|---|
| 01 Book a demo | отрезок, растянутый ×2,2, чуть повёрнут в 3D (медленно поворачивается) | 0 → 0,25 | две точки (вы и мы) появляются полыми кольцами |
| | | 0,25 → 0,7 | между точками вырастает линия, у головы акцентная точка |
| | | 0,7 → 0,85 | точки «наливаются» (кольца заполняются); с 0,7 от середины линии расходится акцентное кольцо (контакт) |
| 02 Pass KYB | квадрат, лежит в наклоне | 0 → 0,8 | сверху вниз идёт акцентная сканирующая линия, пройденная часть слегка залита |
| | | 0,18 / 0,38 / 0,58 / 0,78 | углы по часовой стрелке по очереди «проверяются»: кольцо акцента расходится, угол заливается; сторона от проверенного угла до следующего становится сплошной |
| | | 0,84 → 0,98 | рамка «замыкается»: все стороны один раз вспыхивают акцентом |
| 03 Start the process | куб | 0,04 → 0,66 | вершины появляются, 12 рёбер по очереди вырастают (от первой вершины наружу) |
| | | 0,75 → 1 | по рёбрам (обход Грея, 7 рёбер) бежит акцентная точка со шлейфом — тестовый платёж |
| 04 Go live | тессеракт | 0 → 0,2 | внутренний куб «разворачивается» из внешнего (4-я координата растёт 0 → 1) |
| | | 0,2 → 1 | тессеракт вращается в 4D (скорости как у карточки Crypto Processing), по слоям рёбер дважды бежит волна акцента, вершины на её пути вспыхивают кольцом |

## Где видна
Только в открытой карточке: ряд карточек (от 1440 px) — в свободном поле между номером и заголовком, ширина итоговая (как у текста), поэтому картинка не перестраивается, пока карточка растёт; карточки столбиком — над текстом открытого шага, раскрывается вместе с ним (~200 px). Закрытые карточки без картинки, как в макете. Гифка шага 01 из макета («точки на линии») не используется: её заменяет сюжет 01.

## Как подключено
`StepCard` рисует `StepIllustration` двумя слотами: в ряду (от 1440 px) — поле между номером и заголовком шириной итогового текста (`opacity` с задержкой 0,3 с, как у текста; высота до 260 px по центру), ниже 1440 px — внутри сворачиваемого текста над описанием (176 px на телефоне, 224 px от планшета). Скрытый слот имеет нулевой размер и не рисует. `NextSteps` отдаёт `progress` и `staticProgress` (при reduced-motion 78 %). Тесты: `tests/next-steps.spec.ts` (картинка между номером и заголовком, строится вместе с линией, замирает при удержании, столбиком над текстом, reduced-motion, Dark). Замер при замедлении процессора в 4 раза: долгих задач нет.
