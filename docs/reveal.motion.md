# Появление сайта и блоков: спек анимации

Статус: **реализовано целиком за один заход** (по просьбе дизайнера, без фаз; смотрим результат и правим). Все числа стартовые, подстраиваем глазами вместе с дизайнером. Код: [../src/motion/reveal.tsx](../src/motion/reveal.tsx), токены в [../src/motion/tokens.ts](../src/motion/tokens.ts) (`appear`), тесты [../tests/reveal.spec.ts](../tests/reveal.spec.ts).
Область: загрузка страницы и появление всех блоков при скролле (header, hero, logos, features, industries, global, next-steps, faq, cta, footer). Уже сделанные анимации (глобус, карта шагов, волна логотипов, раскрытие Industries/FAQ) не трогаем, добавляем к ним появление.

## Откат (сделан до начала работы)
- Тег **`stable-before-reveal`** — версия, которая нравится сейчас (коммит `498d489`). Вернуться целиком: `git checkout main` после слияния или `git checkout stable-before-reveal`.
- Работа идёт в ветке **`feature/reveal-animations`**, каждая фаза — отдельный коммит, поэтому откатить можно и одну фазу (`git revert`).
- **Аварийный выключатель:** константа `REVEAL_ENABLED` в `src/motion/tokens.ts`. `false` — сайт без всех появлений, как раньше, без правки блоков.

## Отличия от первого черновика (что сделано иначе)
- **Линии колонок не рисуются:** они нарисованы внутренней тенью контейнера блока (`box-shadow inset`), отдельно их не анимировать без переделки всех блоков. Рисуются линии-разделители FAQ (раньше `border-b`, теперь элемент на `scaleX`), точки на углах «хлопают» (`pop`) после загрузки.
- Добавлены заготовки `drop` (части хедера), `spring` (стеклянные значки), `shutter` (шторка баннера); триггер «сразу после шрифтов» называется `atLoad`.
- `Reveal` / `RevealLines` / `CountUp` сами становятся обычными элементами, если появление выключено (reduced motion, `REVEAL_ENABLED = false`, флаг `velant-reveal=off` в localStorage — его ставит `playwright.config.ts` всем тестам).
- Industries: анимируются заголовок и сами пункты (только opacity); Global: заголовок строками, подзаголовок подъёмом, цифры считаются (старое проявление по прокрутке убрано).

## Принципы
1. **Один язык движения.** Четыре заготовки (ниже), общий easing «мягкая посадка» (`easeOut`, уже в `tokens.ts`), длительности 0,7–1,0 с. Блоки берут заготовки, а не придумывают своё.
2. **Один раз.** Элемент появляется, когда на 25 % виден (с запасом 10 % снизу), и больше не прячется при прокрутке назад. Исключение — Global (сцена привязана к прокрутке).
3. **Каскад короткий.** Внутри группы шаг 60–100 мс, вся группа не дольше ~0,8 с, чтобы ничего не ждать.
4. **Без прыжков раскладки.** Двигаем только `transform` и `opacity` (и blur в заготовке «подъём»); высота и положение элементов не меняются, мерящий код (Industries, Global, Cta) не ломается.
5. **`prefers-reduced-motion`:** без движения и blur, всё сразу в конечном виде (можно мягкий fade 0,2 с).
6. **Текст не страдает:** строки заголовка режутся на `span`-ы, читается и копируется как раньше, скринридер читает один заголовок.
7. Шрифты готовы до старта (`document.fonts.ready`), иначе заголовок прыгнет после появления.

## Четыре заготовки (новый общий модуль `src/motion/reveal.tsx`)
| Имя | Что делает | Где |
|---|---|---|
| **Строки** (`RevealLines`) | каждая строка заголовка выезжает из-под «маски» снизу (y 110 % → 0), строки по очереди (шаг 90 мс), 0,9 с | h1/h2 всех блоков |
| **Подъём** (`RevealUp`) | opacity 0→1, y 24 → 0, blur 6 → 0 px, 0,8 с | подзаголовки, кнопки, описания, абзацы |
| **Карточка** (`RevealCard`) | opacity 0→1, y 48 → 0, scale 0,96 → 1, 0,9 с; в сетке — по очереди слева направо, сверху вниз (шаг 80 мс) | карточки features, шаги, ряды FAQ, футер |
| **Линия** (`RevealLine`) | линия «рисуется» (scaleX/scaleY 0→1 от начала), 1,0 с, мягкий easing | колонки-рамки блоков, разделители FAQ, линия конца блока |

Точки (CornerDots) появляются «хлопком» (scale 0 → 1,3 → 1, 0,5 с) после линии, к которой привязаны.

## Загрузка страницы (первый экран, ~1,6 с в сумме)
1. **0,0 с** Header опускается сверху (y −100 % → 0, opacity), внутри по очереди: логотип, пункты меню, кнопки и переключатель темы (шаг 50 мс).
2. **0,2 с** Точки фона hero проявляются «рябью» от центра к краям: каждая точка растёт (scale 0→1) с задержкой по расстоянию от центра, 1,2 с. Градиент-затухание остаётся.
3. **0,35 с** Заголовок hero: три строки «Строки».
4. **0,75 с** Подзаголовок, затем две кнопки: «Подъём» (шаг 100 мс).
5. **0,95 с** Карточка hero__media: «Карточка» (она пустая-заглушка, потом в ней будет макет).

## Блоки при скролле
- **logos:** строка логотипов выезжает как один «Подъём»; волна логотипов (уже есть) стартует после.
- **features:** линии колонки рисуются сверху вниз; eyebrow «Подъём», заголовок «Строки», девять карточек «Карточка» с каскадом по сетке. Карточки не двигаются во время своей будущей внутренней анимации (иллюстрации придут позже).
- **industries:** заголовок «Строки» при входе в секцию; пункты списка проявляются только через opacity и blur (без сдвига: список едет собственным скользящим механизмом). Закрытые пункты каскадом (шаг 60 мс), открытая карточка — «Карточка».
- **global:** глобус как сейчас. Текст, привязанный к прокрутке, заменяется: заголовок «Строки», подзаголовок «Подъём», **цифры считаются от 0** (99.9 %, 15+, <1 sec) за 1,2 с; запуск, когда глобус встал (прогресс закрепления ≥ 0,6). Остаётся запуск один раз, назад не прячется.
- **next-steps:** заголовок «Строки», описание «Подъём», карточки шагов «Карточка» по очереди; соединительная линия шагов рисуется «Линией».
- **faq («Still have questions?»):** заголовок «Строки» слева; пять вопросов «Карточка» по очереди (сдвиг мягче, y 32), разделитель под каждым вопросом «рисуется» слева направо; открытый ответ раскрывается как сейчас.
- **cta:** баннер раскрывается «шторкой»: `clip-path` от узкой полосы к полному размеру с радиусом 60 (1,0 с); сразу за ним заголовок «Строки», подзаголовок и кнопка «Подъём»; **человек** въезжает снизу (y 60 → 0, 1,0 с); три стеклянных значка «выскакивают» по очереди с лёгким пружинным перелётом (scale 0,6 → 1,05 → 1, шаг 150 мс); точки баннера проявляются «рябью» (как в hero).
- **footer:** колонки «Подъём» с каскадом по колонкам, нижняя полоса (footer-bottom) — fade. Линия над футером «рисуется».

## Что техничнее всего (риски)
- **Industries и Global** измеряют положение элементов и двигают содержимое сами: поэтому там анимация только на заголовке и на самих пунктах (через их opacity/blur/transform внутри), не на обёртках, которые мерятся.
- **InteractiveDots** получает необязательный параметр «рябь появления» (центр и длительность); по умолчанию поведение прежнее, значит UI Kit и остальные места не меняются.
- **Тесты.** 224 теста измеряют положения и прозрачность. Чтобы появление им не мешало, в конфигурации Playwright включается флаг «появление выключено» (значение в `localStorage`, `storageState` в `playwright.config.ts`), а отдельные тесты `tests/reveal.spec.ts` включают его обратно и проверяют: начальное состояние скрыто, конечное видно, один раз, reduced-motion показывает всё сразу. Боевая страница флаг не читает без явной установки (при обычном заходе анимации включены).
- **Вес и производительность:** только transform/opacity (кроме blur у «Подъёма», он ограничен 6 px и снимается после анимации через `filter: none`); цикл рябь-точек живёт только пока играет.
