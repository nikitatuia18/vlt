# UI Kit (дизайн-система проекта)

**Это единая база знаний: сначала смотри здесь, потом пиши своё.** Здесь токены, готовые элементы, готовые анимации и поверхности (стекло, свечение) и правила, когда что брать. Разделы 7–9 — рецепты: что делать, если нужно появление, свечение или сцену темы. Живая витрина с кнопками Replay — `/ui-kit`.

Живая витрина: **http://localhost:5173/ui-kit** (при запущенном `npm run dev`). Она показывает токены и общие компоненты в текущей теме, переключатель Light/Dark — вверху страницы. Код витрины: [../src/ui-kit/UiKitPage.tsx](../src/ui-kit/UiKitPage.tsx); тесты: [../tests/ui-kit.spec.ts](../tests/ui-kit.spec.ts).

## 1. Принципы
1. **Только токены.** Цвета, шрифты и размеры текста — из [tokens.css](../src/styles/tokens.css) и [typography.css](../src/styles/typography.css); значений «из головы» (`#fff`, `text-[17px]`) в компонентах нет. Соответствие Figma → CSS: [tokens-map.md](tokens-map.md).
2. **Одна сущность — один компонент.** Если элемент встретился во втором блоке, он выносится в `src/components/ui/` и попадает в витрину. До этого он живёт внутри блока.
3. **Имя слоя Figma = `data-el`.** Компоненты UI Kit не знают о блоках: `data-el` передаёт блок снаружи.
4. **Тема.** Все цвета — семантические токены, поэтому Dark работает без правок компонента. Одноцветные SVG из Figma рисуются через `Icon` (маска по `currentColor`).
5. **Доступность.** Кнопка без текста — всегда с `aria-label`; ссылки — `<a>`, действия — `<button>`; видимый фокус (`focus-visible`) есть у всех интерактивных элементов.
6. **Состояния.** В макете нарисован только default; hover/active берутся из токенов Figma (`surface-hover`, `surface-brand-hover`, `surface-brand-active`), фокус — контур цвета `typography-brand`.

## 4. Как добавить компонент
1. Проверить витрину: нет ли похожего.
2. Файл в `src/components/ui/`, только токены, `className` пробрасывается; без бизнес-логики блока.
3. Добавить пример в `UiKitPage.tsx` (все варианты и размеры) и строку в таблицу выше.
4. Новый токен или текстовый стиль — сначала в Figma, затем синк (`figma-to-tokens`). Новый класс `type-*` вносится в список текстовых стилей витрины (Tailwind видит только явно написанные имена классов); тест `ui-kit.spec.ts` падает, если список и `typography.css` разошлись.
5. Прогнать `npm run build`, `npm run lint`, `npx playwright test`.

## 6. Интерактивный фон `InteractiveDots` — коротко
**Что это.** Сетка точек (шаг 40 px, точка r = 1), которая отталкивается от курсора и плавно возвращается: фон выглядит живым. Показан в витрине `/ui-kit`, раздел «Interactive background».

**Как взять.**
```tsx
<section className="relative overflow-hidden">
  <div aria-hidden="true" className="pointer-events-none absolute inset-0">
    <InteractiveDots />
  </div>
  {/* контент поверх, с relative */}
</section>
```
Родитель должен быть `relative` с `overflow-hidden`; холст занимает его целиком.

**Затухание книзу (как в Hero).** Поверх точек кладётся градиент в цвет страницы: сверху прозрачный, снизу сплошной.
```tsx
<div aria-hidden="true" className="pointer-events-none absolute inset-0">
  <InteractiveDots />
  <div className="absolute inset-0 bg-linear-to-b from-surface-page/0 to-surface-page" />
</div>
```
Градиент берёт токен `surface-page`, поэтому работает в обеих темах. Высоту обёртки задавайте по макету секции (в Hero — 79,17 % высоты секции, обёртка выше секции на 4,85 %).

**Как устроен.**
- Цвет точек — токен `surface-dots` (Figma `theme/surface/dots`: Light `neutral/400`, Dark `neutral/600`); фон холста прозрачный, поэтому тема работает сама.
- Курсор отслеживается по всему окну, касания игнорируются; клики холст не перехватывает (`pointer-events-none` на обёртке).
- Физика из прототипа: точка в радиусе 150 отталкивается силой, пропорциональной близости, и возвращается со скоростью 0,1 за кадр.
- Цикл анимации идёт, только пока точки движутся и холст виден; при `prefers-reduced-motion` точки статичны.
- Чёткий на retina (учтён `devicePixelRatio`).

## 7. Анимации появления (reveal): правила и рецепты

Код: [../src/motion/reveal.tsx](../src/motion/reveal.tsx), хуки [../src/motion/useReveal.ts](../src/motion/useReveal.ts), числа [../src/motion/tokens.ts](../src/motion/tokens.ts) (`appear`, `easeOut`). Спек и отличия от первого черновика: [reveal.motion.md](reveal.motion.md). Витрина: `/ui-kit`, раздел «Appearance».

### 7.1 Что брать
| Что нужно | Что взять |
|---|---|
| заголовок | `<RevealLines as="h2" lines={['Первая строка', 'вторая']} className="…" />`: каждая строка выезжает из-под маски |
| заголовок или абзац **по словам** | `<RevealLines by="word" lines={['What are our next steps?']} />`: каждое слово выезжает из своей маски, слова друг за другом (шаг 0,07 с; для абзаца `step={0.04}`). Слова переносятся как обычный текст. Пока только в блоке next-steps (проба), в остальных блоках заголовки по строкам |
| текст, кнопка | `<Reveal as="p" delay={0.1}>` (вариант `up`: подъём из лёгкого размытия) |
| карточка, ряд FAQ, шаг | `<Reveal variant="card" delay={index * 0.12}>` |
| часть шапки | `variant="drop"` |
| то, что нельзя двигать (пункты скользящего списка) | `variant="fade"`: только прозрачность |
| крупная фигура снизу (человек на баннере) | `variant="rise"` |
| точка или метка | `variant="pop"` (с перелётом); стеклянный значок: `variant="spring"` (только масштаб) |
| баннер | `variant="shutter"` (раскрывается шторкой) |
| линия-разделитель | `variant="line-x"` / `"line-y"` плюс `origin-left` / `origin-top` и размер 1 px |
| цифра, которая считается | `<CountUp value="99.9%" />` (первое число в тексте считается от 0, остальной текст остаётся, ширина не прыгает) |
| фон из точек | `<InteractiveDots ripple={{ delay, duration, origin }} />` |

### 7.2 Когда играет
- **по умолчанию**: когда элемент виден на 20 % (запас 8 % от низа экрана), один раз, назад не прячется;
- `when={флаг}`: блок сам решает (текст Global ждёт, пока глобус встанет);
- `atLoad`: сразу после загрузки шрифтов (первый экран: шапка, hero);
- `atPageEnd`: для того, что стоит в самом конце страницы (нижняя полоса футера): выше нижнего запаса прокрутить нельзя.

### 7.3 Правила
1. Двигаем только `transform` и `opacity` (плюс blur 6 px у `up`, он снимается в конце). Высоту, ширину и положение не меняем: блоки, которые мерят содержимое (Industries, Global, Cta), анимируем по заголовкам и пунктам, а не по обёрткам, которые меряются.
2. Шаг между соседями 0,06–0,15 с, вся группа не дольше ~0,8 с. Длительности и дистанции берём из `appear`, свои числа в блоках не заводим.
3. Элемент с `backdrop-filter` (стеклянные значки) не прячем через прозрачность родителя: размытие внутри полупрозрачной обёртки пропадает и включается рывком. Для таких: `spring` (масштаб) или анимация без opacity.
4. Если внутри масштаб через `transform: scale` (бейджи cta), обёртка без размера (`h-0 w-0`), а содержимое `w-max`: иначе на телефоне появится горизонтальный скролл.
5. `prefers-reduced-motion`, аварийный выключатель и тестовый флаг превращают `Reveal`, `RevealLines` и `CountUp` в обычные элементы: ничего не спрятано, ничего не двигается.
6. Заголовок остаётся одним текстом (строки это `span`-ы с пробелами между ними), читается и копируется как раньше.

### 7.4 Выключатели
- **Аварийный:** `REVEAL_ENABLED = false` в `src/motion/tokens.ts`: весь сайт без появлений.
- **Тесты:** `localStorage['velant-reveal'] = 'off'`; `playwright.config.ts` ставит это всем тестам, `tests/reveal.spec.ts` включает обратно.

### 7.5 Рецепт: появление нового блока
1. Заголовки: `RevealLines`; подзаголовки и кнопки: `Reveal` с `delay` +0.1 за шаг.
2. Карточки: `Reveal variant="card"`, задержка `index * appear.card.step`.
3. Нужной заготовки нет: добавить вариант в `variants` (`reveal.tsx`) и числа в `appear`, затем плитку в `/ui-kit`, затем строку в таблицу 7.1.
4. Проверить: Replay в витрине, `prefers-reduced-motion`, нет горизонтального скролла на 393, тесты с флагом «выкл» зелёные.

## 8. Свечение

### 8.1 `GlowBackdrop`: свет за карточкой
Размытый эллипс цвета (слой `Ellipse 215` макета: радиальный градиент цвет → прозрачный, blur 100). Цвет: токен `surface-glow-{violet|pink|orange|blue|green}` (исключение без переменных Figma, см. tokens-map.md). Свечения кладут слоями и показывают одно (`visible`): они перетекают за 0,7 с. Нужен позиционированный родитель, размер и место задаёт `className`.

### 8.2 Что пробовали и убрали: настоящее стекло и параллакс
Карточка тёмной сцены была настоящим стеклом (эффект Glass из Figma: размытие, преломление края через SVG-фильтр, блик за курсором) и свечение двигалось за курсором. На слабом компьютере это тормозило: при смене сцены долгая задача и задержка текста. Решение дизайнера: убрать. Сейчас карточка это прозрачная заливка `surface-white-16` и тонкое кольцо, **без `backdrop-filter`**, свечение статичное. Правило: тяжёлые эффекты (`backdrop-filter`, особенно с `url()`, большие `blur`, canvas-карты в движущихся блоках) не добавляем без замера с `CPUThrottlingRate` ×4 (см. lessons.md).

## 9. Тема и сцены
- Тема живёт в `data-theme` на `<html>` (`src/lib/theme.ts`). Два слоя: **выбор посетителя** (переключатель) и **принудительная тема от блока**.
- `useForcedTheme('dark' | null)` в блоке на время его сцены: страница целиком темнеет, переключатель блокируется (луна, `disabled`, подсказка), после сцены сайт возвращается к выбору посетителя. Несколько сцен не мешают друг другу (побеждает последняя).
- `useTheme()` отдаёт `theme`, `locked`, `setTheme`.
- Смена темы плавная на всём сайте: на `<html>` на 0,8 с класс `theme-fading` (правило в `index.css`, слой base, нулевая специфичность: элементы с собственным переходом его сохраняют). При reduced motion и в тестах (флаг) смена мгновенная.
- **Тёмная часть страницы без смены всей темы:** `data-theme="dark"` на любом элементе переворачивает токены внутри него (так сделаны тёмные панели витрины). Для сцены на весь сайт нужен `useForcedTheme`.
- Пример сцены: блок Industries ([blocks/industries.md](blocks/industries.md)). Поле `glow` у пункта включает тёмную сцену, свечение своего цвета, стеклянную карточку и белую кнопку.
