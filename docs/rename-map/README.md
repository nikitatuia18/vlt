# Карты переименований слоёв

Точная карта «nodeId → старое имя → новое имя» по секциям кадра `desctop / home page` (`1110:8484`). Правила имён — [../naming-spec.md](../naming-spec.md).

**Статус:** черновик, ждёт подтверждения пользователя. В Figma ничего не применено.

## Состав
`desktop/` — по файлу на секцию: `header`, `hero`, `logos`, `features`, `industries`, `global`, `next-steps`, `faq`, `cta`, `footer`, `footer-bottom` и `root` (кадр страницы, обёртка, 8 угловых эллипсов). Всего **682 записи**, по числу слоёв из аудита.
Мобильный кадр `1143:3916` — позже: те же имена блоков и элементов, отличается только корень (`page-home--mobile`).

## Формат
```json
{ "block": "hero", "viewport": "desktop", "rootNodeId": "1110:8486", "status": "draft",
  "rename": [ [ "nodeId", "старое имя", "новое имя", "примечание (необязательно)" ] ] }
```
Примечание, начинающееся с `?`, — решение ждёт пользователя. Старое имя нужно для проверки: перед переименованием слой должен называться именно так, иначе он пропускается и попадает в отчёт.

## Проверки (пройдены)
682 записи; 0 нарушений грамматики; имена ≤ 40 символов; 0 дублей id; 0 дублей имён (кроме `icon-*`/`img-*`, которым повтор в разных родителях разрешён); у каждого слоя префикс своего блока; нет авто-имён.

## Применение (после подтверждения)
1. Бэкап страницы в Figma (дубликат).
2. Переименование по секциям: проверка старого имени, запись нового; меняется только `name`.
3. Повторное чтение дерева и сверка с картой; затем `status: "applied"` и заполнение `docs/figma-map.json`.

## Открытые вопросы
Подробные примечания — в записях с `?` в соответствующих файлах. Главное:

1. **logos** — бренд логотипа-звёздочки (3 копии в ленте): имя `logos__item-asterisk` временное. Остальные плитки определены по изображению: bybit, utila, fill, apple-pay, google-pay, alltrust, sepa, swift.
2. **global** — маршруты на карте (9 линий) названы по концам (`global__route-ca-eu` …), определены по скриншоту, уверенность низкая; запасной вариант — `global__route-1…9`. Метрики названы по тексту (`global__metric-rails`, `global__metric-latency`), хотя слои в макете называются «Countries/Currencies Supported».
3. **global** — детач-флаг ЕС (`1110:8969`) в Figma называется `Flags/Canada`; рекомендуется заменить на инстанс флага Европы.
4. **root** — 8 угловых эллипсов стоят на стыках секций; привязка к блоку (`faq`, `cta`, `footer`) предварительная.
5. **footer** — логотип: `footer__logo` с буквами `footer__logo-letter-*` или один `img-logo-velant-pay`.
6. **faq** — кнопки раскрытия — инстансы компонента (`icon-collapse-button`, `icon-expand-button`); возможно, лучше называть `faq__item-*-toggle`.
7. **features** — карточки Banking и Wallet лежат в общей колонке (`features__col-soon`); префиксы `ramp-counter-prefix/suffix` вне списка ролей текста.
8. **industries** — первая серая строка списка может быть подзаголовком, а не пунктом (`industries__list-caption`).
