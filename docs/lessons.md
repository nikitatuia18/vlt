# Журнал уроков

## 2026-10-19 · CSS · маленький элемент в строке садится на базовую линию
Точка 5 px, обёрнутая в обычный `<span>`, получила высоту строки (24 px) и села на её базовую линию: оказалась на 6 px выше нужного места. Замеры (`getBoundingClientRect`) показали это сразу. Мелкие декоративные элементы класть в `flex`/`grid`-обёртку (или `block`) с явным размером; положение проверять тестом по центру элемента относительно линии.

## 2026-10-19 · Тесты · «не двигается» проверять по всему прямоугольнику
Заголовок в колонке рядом со списком «ездил», потому что ширина колонки зависела от ширины списка, а мой тест сравнивал только `y`. Для «элемент неподвижен» сравнивать x, y, ширину и высоту при каждом состоянии соседей (каждый пункт открывается по очереди) и на всех ширинах. Элемент, который не должен зависеть от соседа, ставить вне его потока.

## 2026-10-19 · Анимация · центрирование в оставшейся высоте даёт пустоту
Если список «центрирует» активный пункт в области, то у первого пункта сверху остаётся пустая полоса (особенно заметно на узких экранах). Нужен зажим: в начале список у верха, в конце у низа, центрирование только в середине; если список целиком помещается — центрировать целиком. Затухание у краёв включать только там, где список реально обрезан.

## 2026-10-19 · Windows · файлы, различающиеся только регистром
`Industries.tsx` и `industries.ts` на Windows — один и тот же файл: TypeScript ругается (TS1149), а запущенный dev-сервер Vite запоминает неверный файл и после переименования отдаёт пустую страницу (все тесты падают на «элемент не найден»). Файлы данных блока называем иначе, чем компонент (`cards.ts`, `brands.ts`, `items.ts`). После переименования файлов dev-сервер **перезапускать**.
**Как диагностировать:** при массовом «элемент не найден» сначала ловить `pageerror` страницы, а не править тесты.

## 2026-10-19 · Анимация · закреплённая секция по прокрутке
Схема: высокая секция (`100svh + (n−1) × шаг vh`) со `sticky`-сценой; активный пункт = `floor(progress × n)` из `useScroll`; список подтягивается к центру области кадровым циклом (чтение `offsetTop` открытого пункта и сглаживание), а не расчётом высот: так движение мягкое при любой высоте раскрывающейся карточки. Тесты прокручивают секцию до долей 0…1 и ждут ~1,6 с, пока всё успокоится.

## 2026-10-19 · Figma → CSS · рамка в сгенерированном коде сужает содержимое
Figma-обводка лежит внутри и размер не меняет, а `border` из сгенерированного кода сужает содержимое (две рамки по 1 px = −2 px ширины сетки); тест по размерам из макета это поймал. Рамки и обводки переносить как `ring-1 ring-inset`, а не `border`, кроме случая, когда в макете рамка действительно в потоке (например, нижняя граница секции).

## 2026-10-19 · Макет · бренд по миниатюре опознан неверно
Логотип «Flitt» я назвал «Fill», глядя на скриншот узла 1024 px шириной; ошибка дошла до слоёв Figma и кода и вскрылась только на кадре в полном размере.
**Как применять:** названия брендов, надписи и значки опознавать по увеличенному фрагменту (скриншот самого узла или скачанный ассет), а не по общему виду секции; если сомнение остаётся — одной строкой спросить пользователя до переименования слоёв.

## 2026-10-19 · Анимация · разбирать образец по коду, а не по ощущению
Пользователь описал эффект сайта-образца словами («волна ускоряется при скролле»), а в коде оказалось другое: фиксированные иконки, волна с периодом 7 с и отдельный сдвиг ленты на 250 px, привязанный к прокрутке. Скрипты Astro-сайта лежат в `/_astro/*.js` и читаются, если скачивать с `curl --compressed` (иначе приходит gzip).
**Как применять:** на «сделай как у них» сначала скачать и прочитать скрипт и стили (в изолированную папку, не запускать), записать, что реально происходит, и сказать пользователю, чем оно отличается от его описания. Код образца не копировать, а повторять приём.

## 2026-10-19 · Анимация · кривая с периодом, не равным периоду набора
Если набор повторяется каждые N плиток, а кривая — каждые M, привязка высоты к плитке ломает бесшовность при беге плиток. Тогда либо высота — функция положения `x` (плитки скользят по кривой), либо плитки стоят, а бежит фаза волны (как сейчас): петля одна, период волны.

## 2026-10-19 · Layout · max-width с padding занижает колонку
`max-w-[1440px] px-20` при `box-sizing: border-box` даёт содержимое 1280 px, а в макете колонка 1440 px, и отступ лежит снаружи. Заметили только тестом на ширине кадра макета (2560). Решение: `max-w-[calc(var(--container-page)+2*var(--gutter))]` в `Container`.
**Как применять:** размеры из макета проверять тестом на ширине самого кадра (2560 для десктопа), а не только на «обычных» ширинах.

## 2026-10-19 · Токены · get_variable_defs неполон, в файле есть тёмная тема
`get_variable_defs` по узлу отдаёт только привязанные к нему переменные и только значения текущего режима. Полный набор и режимы (в этом файле есть Light/Dark!) читаем через `use_figma`: `figma.variables.getLocalVariableCollectionsAsync()`, `getLocalVariablesAsync()`, `getLocalTextStylesAsync()`; алиасы вида `color + opacity` резолвим отдельным чтением переменных по id.
**Почему:** первые токены были собраны по `get_variable_defs` и пропустили 2/3 набора, включая тёмную тему и hover-цвета кнопки.
**Как применять:** любой синк токенов начинать с полного чтения; перед выводами «в Figma нет X» проверять полным списком.

## 2026-10-19 · Tailwind · классы из `@utility` нельзя собирать из строк
Tailwind генерирует только те классы, имена которых целиком написаны в исходниках. `type-${name}` или список из `?raw`-CSS не сработают: стиль не попадёт в сборку. Имена пишем явно (список в витрине), а тест сверяет список с `typography.css`.

## 2026-10-19 · Тесты · ленивые страницы и скриншоты
Страница за `React.lazy` в момент `goto` ещё пустая: скриншот получится белым, хотя тесты на элементы зелёные. Перед снимком ждать заголовок страницы.

## 2026-10-19 · Tailwind · `hidden` проигрывает базовому display компонента
Если у компонента в базовых классах есть `inline-flex`, а снаружи передан `hidden desktop:inline-flex`, то на узких экранах элемент остаётся видимым (в итоговом CSS побеждает `inline-flex`). Тест на мобильной ширине это поймал.
**Как применять:** для скрытия по ширине использовать вариант `max-desktop:hidden` / `desktop:hidden` (варианты идут в CSS позже базовых утилит), либо обёртку; голый `hidden` на компоненте со своим `display` не использовать.

## 2026-10-19 · Тесты · кнопки с transition-colors
Скриншот сразу после смены темы ловит кнопки посреди анимации цвета (150 мс): они выглядят «светлее» остальных. Перед снимком ждать установившегося значения (`toHaveCSS`), а не `waitForTimeout`.

## 2026-10-19 · Figma MCP · метаданные неполны, запись сверяем по старому имени
`get_metadata` не показывает детей листовых фреймов (иконки, логотипы): в кадре 808 узлов, аудит видел 682. Для точного подсчёта и проверки результата нужен обход дерева через `use_figma` (чтение, один вызов на кадр).
Массовое переименование делаем скриптом `use_figma` по карте `[id, старое имя, новое имя]`: слой с другим старым именем пропускается и попадает в отчёт; скрипт идемпотентен (уже переименованный пропускается). Перед записью — копия кадра рядом.
**Как применять:** любые массовые правки в Figma — по карте с проверкой старого значения; после правок — независимая проверка живого дерева, а не только отчёт скрипта.

## 2026-10-19 · Figma MCP · лимит вызовов
Лимит чтения Figma MCP для нашего места (Full, Professional): **200 вызовов в сутки и 10 в минуту**; время сброса в документации не указано. Аудит десктопа (~33 вызова) и мобильного кадра (~117 вызовов подбором id) исчерпал дневной лимит, мобильный аудит остался неполным.
**Почему:** `get_metadata` верхнего кадра не возвращает детей, и субагент перебирал id вслепую (большинство «not found»).
**Как применять:** планировать бюджет вызовов заранее; не подбирать id перебором — брать nodeId блоков из ссылок на выделенные пользователем узлы или обходить по известным родителям; тяжёлые обходы делать одним агентом и сохранять карту id в `docs/figma-map.json` сразу, чтобы не повторять; в конце этапа оставлять запас на вызовы.

## 2026-10-19 · Тесты · данные с импортом SVG
Playwright не умеет импортировать .svg (ошибка «does not provide an export named default»). Тесты не импортируют модули данных, которые тянут картинки (pins.ts, outes.data.ts); id перечислены прямо в тесте. Модули без картинок (items.ts) импортировать можно.

## 2026-10-19 · motion · штрих и его смещение
Две анимации (`strokeDasharray` и `strokeDashoffset`) на одном `motion.path` с `style`-значением смещения: смещение не менялось, линия «с конца» была невидима. Для проявления линии держим одно значение прогресса (`useMotionValue` + `animate`) и считаем из него обе величины (`useTransform`). Скругление концов (`round`) оставляет точку при нулевой длине — ставим плоские концы.

## 2026-10-19 · Figma Motion · обрезанный цикл
`get_motion_context` отдаёт цикл кадра (здесь 11,18 с), а ключевые кадры за его границей урезает до последнего значения. Если появление чего-то выглядит «в самом конце цикла» — это признак; полные тайминги брать из Lottie-экспорта дизайнера (кадры ÷ 60).

## 2026-10-19 · Анимация · линия «зависла»
Если после правки линия или элемент «стоит всегда» — сначала сверить, нет ли у него ключевых кадров за границей обрезанного цикла Figma (первый ключевой кадр на 12 с при цикле 11,18 с). Лишний повод: окно между первым и вторым ключевым кадром у линий всегда ~108 кадров (1,8 с) — это окно рисования.

## 2026-10-19 · Верстка · ширина через flex-grow
При `flex-basis: 0` и `box-sizing: border-box` паддинги карточек не входят в долю роста: доли `grow` дают ширину СОДЕРЖИМОГО плюс паддинги. Чтобы получить размеры макета (500 и 262 px), в `grow` ставим ширину текстовой области (420 и 182), а не ширину карточки. Playwright считает `visible` текст, свёрнутый по высоте внутри `overflow: hidden` — такую свёртку проверять по высоте обёртки.
