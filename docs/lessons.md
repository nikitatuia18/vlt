## 2026-10-19 · Макет · бренд по миниатюре опознан неверно
Логотип «Flitt» я назвал «Fill», глядя на скриншот узла 1024 px шириной; ошибка дошла до слоёв Figma и кода и вскрылась только на кадре в полном размере.
**Как применять:** названия брендов, надписи и значки опознавать по увеличенному фрагменту (скриншот самого узла или скачанный ассет), а не по общему виду секции; если сомнение остаётся — одной строкой спросить пользователя до переименования слоёв.

## 2026-10-19 · Анимация · бег по кривой считать от положения, а не от плитки
Если набор повторяется каждые N плиток, а кривая — каждые M, привязка высоты к плитке ломает бесшовность. Высота должна быть функцией положения `x`, а смещение сбрасываться через N плиток (кратно количеству брендов).

## 2026-10-19 · Layout · max-width с padding занижает колонку
`max-w-[1440px] px-20` при `box-sizing: border-box` даёт содержимое 1280 px, а в макете колонка 1440 px, и отступ лежит снаружи. Заметили только тестом на ширине кадра макета (2560). Решение: `max-w-[calc(var(--container-page)+2*var(--gutter))]` в `Container`.
**Как применять:** размеры из макета проверять тестом на ширине самого кадра (2560 для десктопа), а не только на «обычных» ширинах.

## 2026-10-19 · Токены · get_variable_defs неполон, в файле есть тёмная тема
`get_variable_defs` по узлу отдаёт только привязанные к нему переменные и только значения текущего режима. Полный набор и режимы (в этом файле есть Light/Dark!) читаем через `use_figma`: `figma.variables.getLocalVariableCollectionsAsync()`, `getLocalVariablesAsync()`, `getLocalTextStylesAsync()`; алиасы вида `color + opacity` резолвим отдельным чтением переменных по id.
**Почему:** первые токены были собраны по `get_variable_defs` и пропустили 2/3 набора, включая тёмную тему и hover-цвета кнопки.
**Как применять:** любой синк токенов начинать с полного чтения; перед выводами «в Figma нет X» проверять полным списком.

## 2026-10-19 · Tailwind · классы из `@utility` нельзя собирать из строк
Tailwind генерирует только те классы, имена которых целиком написаны в исходниках. `type-${name}` или список из `?raw`-CSS не сработают: стиль не попадёт в сборку. Имена пишем явно (список в витрине), а тест сверяет список с `typography.css`.

## 2026-10-19 · Тесты · ленивые страницы и скриншоты
Страница за `React.lazy` в момент `goto` ещё пустая: скриншот получится белым, хотя тесты на элементы зелёные. Перед снимком ждать заголовок страницы.

## 2026-10-19 · Tailwind · `hidden` проигрывает базовому display компонента
Если у компонента в базовых классах есть `inline-flex`, а снаружи передан `hidden desktop:inline-flex`, то на узких экранах элемент остаётся видимым (в итоговом CSS побеждает `inline-flex`). Тест на мобильной ширине это поймал.
**Как применять:** для скрытия по ширине использовать вариант `max-desktop:hidden` / `desktop:hidden` (варианты идут в CSS позже базовых утилит), либо обёртку; голый `hidden` на компоненте со своим `display` не использовать.

## 2026-10-19 · Тесты · кнопки с transition-colors
Скриншот сразу после смены темы ловит кнопки посреди анимации цвета (150 мс): они выглядят «светлее» остальных. Перед снимком ждать установившегося значения (`toHaveCSS`), а не `waitForTimeout`.

## 2026-10-19 · Figma MCP · метаданные неполны, запись сверяем по старому имени
`get_metadata` не показывает детей листовых фреймов (иконки, логотипы): в кадре 808 узлов, аудит видел 682. Для точного подсчёта и проверки результата нужен обход дерева через `use_figma` (чтение, один вызов на кадр).
Массовое переименование делаем скриптом `use_figma` по карте `[id, старое имя, новое имя]`: слой с другим старым именем пропускается и попадает в отчёт; скрипт идемпотентен (уже переименованный пропускается). Перед записью — копия кадра рядом.
**Как применять:** любые массовые правки в Figma — по карте с проверкой старого значения; после правок — независимая проверка живого дерева, а не только отчёт скрипта.

## 2026-10-19 · Figma MCP · лимит вызовов
Лимит чтения Figma MCP для нашего места (Full, Professional): **200 вызовов в сутки и 10 в минуту**; время сброса в документации не указано. Аудит десктопа (~33 вызова) и мобильного кадра (~117 вызовов подбором id) исчерпал дневной лимит, мобильный аудит остался неполным.
**Почему:** `get_metadata` верхнего кадра не возвращает детей, и субагент перебирал id вслепую (большинство «not found»).
**Как применять:** планировать бюджет вызовов заранее; не подбирать id перебором — брать nodeId блоков из ссылок на выделенные пользователем узлы или обходить по известным родителям; тяжёлые обходы делать одним агентом и сохранять карту id в `docs/figma-map.json` сразу, чтобы не повторять; в конце этапа оставлять запас на вызовы.
