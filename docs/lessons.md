## 2026-10-19 · Figma MCP · лимит вызовов
Лимит чтения Figma MCP для нашего места (Full, Professional): **200 вызовов в сутки и 10 в минуту**; время сброса в документации не указано. Аудит десктопа (~33 вызова) и мобильного кадра (~117 вызовов подбором id) исчерпал дневной лимит, мобильный аудит остался неполным.
**Почему:** `get_metadata` верхнего кадра не возвращает детей, и субагент перебирал id вслепую (большинство «not found»).
**Как применять:** планировать бюджет вызовов заранее; не подбирать id перебором — брать nodeId блоков из ссылок на выделенные пользователем узлы или обходить по известным родителям; тяжёлые обходы делать одним агентом и сохранять карту id в `docs/figma-map.json` сразу, чтобы не повторять; в конце этапа оставлять запас на вызовы.
